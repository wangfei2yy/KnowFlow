# 知间 AI（KnowFlow）

**AI 万能资料管家 · 个人知识与行动中心**

> 让知识不止于收藏，让信息最终成为行动。

知间 AI 帮助你把零散资料转化为可检索的知识和实际行动：收藏文本、笔记、文件与网页内容，通过 AI 生成摘要、回答问题、提取待办，并整理成复习卡片。

## 核心特性

- 📚 **资料管理**：新增/编辑/删除、分类、标签、收藏，来源类型差异化输入（笔记/文本/文件/网页）
- 🔍 **全文搜索**：中文友好（n-gram 分词）、关键词高亮、分类/收藏筛选
- ✨ **AI 增强**：摘要、有来源的资料问答、行动项提取、记忆卡片生成（张数可自定义或由 AI 自动判断），支持自备 Key + 连接测试
- ✅ **任务管理**：优先级、截止时间、逾期标记、回溯来源资料
- 🎴 **学习模式**：复习翻卡 + 列表双视图、按分类/熟悉度筛选与排序、掌握程度标记
- 🤖 **陪伴机器人「小知」**：鼓励学习、好感度成长、三形态进化、可拖动、软件答疑、AI 智能对话与工具调用（一句话生成卡片/摘要/任务）
- 📥 **导入导出**：TXT/MD/PDF 导入、JSON 备份恢复
- 🔒 **本地优先**：数据存浏览器，无需注册、无需配置即可体验

## 快速开始

```bash
cd frontend
npm install
npm run dev        # 开发预览
npm run build      # 生产构建
```

> 默认使用「演示模式」，无需 API Key 即可体验全部 AI 功能。
