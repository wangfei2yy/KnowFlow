# 小红书小工具构建与发布

> 本文记录 KnowFlow 打包为「小红书小工具」（离线 H5 zip）的构建方式、容器适配改造与验证结论。
> 返回主文档：[项目说明文档](项目说明文档.md)

---

## 一、产物与命令

| 项 | 值 |
| --- | --- |
| 构建命令 | `cd frontend && npm run build:minitool` |
| 产物目录 | `frontend/dist-minitool/` |
| 上传包 | `knowflow-minitool.zip`（项目根目录，约 1.2 MB） |
| 包内结构 | `index.html`（根目录）+ `assets/app.js` + `assets/style.css` + `icons/`（应用图标） |
| 渲染冒烟测试 | `cd frontend && npm run test:render`（jsdom 加载产物验证挂载与按钮点击） |

zip 内 `index.html` 必须在**根目录**（不能多套一层文件夹），否则容器无法加载。

## 二、容器约束与对应改造

小工具本质是**离线 H5**：资源全部打包、**不能联网**、脚本必须是 classic script。因此单独一套构建，不改动网页版产物。

| 容器约束 | 改造方式 |
| --- | --- |
| 禁止 `fetch` / XHR 联网 | 构建期用替身模块替换 `OpenAICompatibleProvider`（`src/minitool/openai.stub.ts`），产物中 `fetch(` 出现次数为 0 |
| 禁止 Web Worker（pdfjs 依赖） | 替换 `pdfjs-dist` 为 stub，`parseFile` 在端内直接返回「不支持文件导入」提示 |
| 禁止 `import.meta` / ES Module | 构建 `format: "iife"` + `inlineDynamicImports`，并把 `index.html` 的 `<script type="module">` 改写为 **`<script defer>`**（⚠️ 关键：module script 默认延迟执行，改 classic 后必须显式补 `defer`，否则脚本会在 `<div id="app">` 解析前同步执行，Vue 挂载失败、整页按钮全部无效——首轮审核「功能缺陷：页面按钮无法点击」即此问题） |
| 禁止内联脚本与行内事件 | Vue 事件全部通过 `addEventListener`（编译产物自带），无内联 `<script>` |
| 禁止 `a[download]` / blob 下载 | `downloadJSON` 拆到 `utils/download.ts`，小工具构建替换为抛错提示；设置页隐藏备份区 |
| 禁止打开外链 / `target="_blank"` | 资料详情的网页来源改为「可选中文本」展示 |
| 无麦克风权限 / 无网络 | 语音输入整体禁用：`whisperRecorder` 与 `transcribe` 均替换为替身，产物中 `getUserMedia` / `MediaRecorder` / `fetch` 出现次数为 0，麦克风按钮不渲染 |
| 禁止 IndexedDB 作为可靠存储 | 用 `xhs.miniTool` Storage API（JSON 字符串）实现 `LiteTable`，Dexie 代码不进包 |
| Chrome 61 / ES2017 基线 | `build.target: ["es2017", "chrome61"]` |
| 不得自建 CSP `<meta>` | 构建时移除 `index.html` 中的 CSP 元信息，交由容器统一管理 |
| 文件选择器仅支持图片/视频 | 导入页与编辑页在端内隐藏「文件」类型，引导用文本/笔记录入 |

### 存储实现（LiteTable）

`src/db/liteStore.ts` 用「整表 JSON + 内存镜像」实现 Dexie 的最小 API 子集：

- 读写优先走 `xhs.miniTool.getStorage / setStorage`，失败或低版本（< 9.46）回退 `localStorage`
- 单 key 上限 1 MB，总量 10 MB；超限写入会被忽略，内存镜像仍可用
- 支持 `add / put / update / delete / get / toArray / count / clear / bulkAdd / bulkPut / orderBy().reverse() / where().equals() / transaction`
- `update` 保留 Dexie 语义：字段值为 `undefined` 即删除该字段

- `vibrateShort / vibrateLong`、陀螺仪（9.50+）、`followAuthor / getFollowStatus`（9.51+）

> `AI.createModel` 属**内测加白**能力，文档未提供完整对外说明，本项目未使用。

## 五、已知限制（端内离线版）

1. **AI 无法联网**：容器禁止任何网络请求，端内为「演示模式」——摘要 / 卡片 / 任务由本地规则生成，非真实模型输出
2. **文件导入不可用**：容器仅允许选择图片/视频，且 PDF 解析依赖 Worker
3. **备份导入导出不可用**：`a[download]` 与文件选择受限；导入页已给出替代引导
4. **语音输入不可用**：容器无麦克风权限且禁网，小知只能打字；浏览器识别与录音上传两条通道在端内均关闭
5. **网页来源链接不可点击**：仅作为文本展示，可长按复制
6. **CSS 布局风险**：Tailwind 大量使用 flex `gap`，Chrome 61 不支持 flex gap，Android 8.1 老机型上间距会丢失；iOS 18.4+ 正常
7. **性能未实测**：未在创服平台模拟器与真机上运行，帧率、首屏、内存均无实测数据

## 六、上传与验证步骤

1. 打开小红书小工具创服平台，创建/进入小工具；
2. 上传根目录的 `knowflow-minitool.zip`；
3. **先在平台模拟器**完成完整功能验证（新增资料、搜索、任务、学习卡片、小知对话）；
4. 再用 **Android 真机**扫码验证同一产物；
5. 最后用 **iOS 真机**扫码验证；
6. 三项通过后再提交审核。

> 浏览器直接打开 `dist-minitool/index.html` 的结果不能作为验收依据（容器会注入 `window.xhs`，且 CSP / 存储行为不同）。
