## 一、资料管理

### 1.1 基本 CRUD

- 新增、编辑、删除资料，详情页可查看全文、摘要、关键词与关联内容
- 所有写操作均有确认反馈，删除有二次确认

### 1.2 组织体系

| 维度 | 说明 |
| --- | --- |
| 分类 | 支持增删改；导入页可直接新建分类，不必跳转设置页 |
| 标签 | 一个资料可打多个标签，搜索时可命中 |
| 收藏 | 收藏的资料在首页「最近资料」与资料库筛选中优先展示 |

### 1.3 来源类型差异化输入

新增资料时，按来源类型切换对应的输入方式：

| 来源类型 | 输入方式 |
| --- | --- |
| 笔记 | 直接输入正文（富文本简化输入） |
| 文本 | 直接输入正文 |
| 文件 | 显示上传区，TXT / MD / PDF 自动解析正文回填 |
| 网页 | 显示链接输入框，保存后详情页可点击跳转原网页 |

默认分类会跟随来源类型智能预选（如选择「文件」默认归入「文档」类），且分类下拉支持「新建分类」入口。

### 1.4 示例资料（首次体验）

- 首次使用（本地无数据且无已加载标记）时**自动加载 7 条示例资料**，覆盖笔记 / 文本 / 文件 / 网页四种来源类型；
- 其中「项目周会记录」「产品需求文档」两条示例**预置了关联任务**，用于演示「资料 → 行动项」闭环；
- 无任务可提取的示例（如英语口语表达）会给出友好提示，而非报错；
- 示例数据可通过「清除本地数据」一键移除。

### 1.5 首页快捷操作（2026-10-30 重整合）

原来是 7 个入口，逐个点过去核对时发现这些问题：

| 问题 | 现象 | 改法 |
| --- | --- | --- |
| 「AI 整理」名不副实 | 和「资料问答」都跳 `/assistant` 且不带参数，落地永远是「问答」Tab | 带 `?tab=summary` / `?tab=qa`，落到对应 Tab（页面本来就支持 `route.query.tab`） |
| 「学习复习」绕路 | 跳 `/study` 概览，还要再点一次 | 直达 `/study/cards` |
| 旧路径靠 redirect 兜 | 「单词闯关」用 `/study/quest`，靠路由 redirect 转 | 直接用新路径，并改为「趣味学习」总入口 `/study/play` |
| 缺入口 | 「文件导入」`/import` 真实存在却没入口；学习侧没有「单词表」「趣味学习」 | 补齐 |
| 端内显隐靠硬编码 | `startsWith("/kitchen")` + 三个路径写死，加新项必漏 | 每项带 `minitool` 标记，`filter((a) => a.minitool)` |

最终 8 项（2×4 网格，正好两行）：新增资料 / 文件导入 / AI 整理 / 资料问答 / 卡片复习 / 单词学习 / 趣味学习 / 今天吃什么。

端内（小红书小工具）只保留不依赖在线词库与文件解析的四项：新增资料、AI 整理、资料问答、卡片复习。

逐项点击验证过：8 个入口的 `location.hash` 与目标页标题一致，无错误页；
`/assistant?tab=summary` 落地后 Tab 确实停在「生成摘要」。

## 二、全文搜索

### 2.1 能力

- 标题、正文、标签多字段检索
- 中文采用「单字 + bigram」n-gram 分词，不依赖英文空格，中文友好
- 标题命中优先打分排序
- 命中关键词在结果中高亮
- 支持按分类、收藏状态进一步筛选

### 2.2 交互

- 首页搜索框输入关键词后按回车，跳转资料库并展示搜索结果
- 资料库页的搜索框独立可用，与首页搜索共享同一套检索引擎

---

## 三、文件导入

- 支持 **TXT、Markdown、PDF**（pdfjs-dist 提取文本）
- 解析后先预览，确认标题 / 分类 / 标签后再入库
- 单文件 10 MB 上限，批量导入后展示导入结果清单（成功/失败分明）
