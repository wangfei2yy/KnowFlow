# 模块 06 · 内置知识包与单词闯关

> 目标：让「没有自己的资料」的新用户也能立刻开始 —— 内置英语语法专题与四/六级词库，
> 并用闯关把背单词变成可持续的动作。答错的词直接进入复习队列，复用 M1 的 SRS 调度。

---

## 一、数据来源与编译

原始素材放在仓库根目录 `data/英语/`：

```
data/英语/
├── 单词/大学英语四级词汇-乱序版-答案.pdf   （296 页）
├── 单词/大学英语六级词汇-乱序版-答案.pdf
└── 语法/**/*.md                            （50 篇，按语法点分目录）
```

编译命令（在 `frontend/` 下执行，可重复跑）：

```bash
npm run build:packs
```

脚本 `scripts/build-packs.mjs` 做三件事：

| 步骤 | 说明 |
| --- | --- |
| PDF 解析 | 用 `pdfjs-dist` 读取文本片段，**按表头（序号/单词/音标/释义）动态识别列边界**，再按最近的序号行聚合为词条；两本 PDF 的列坐标相差约 8pt，硬编码阈值会串列 |
| 释义清洗 | 去掉「人名/地名」等考试无关义项，超长截断到 150 字 |
| 语法归集 | 遍历 `语法/` 目录，取一级标题为标题、目录名为分类，按分类 + 文件名排序 |

产物（提交到仓库，部署时直接静态托管）：

```
frontend/public/packs/
├── index.json      { version, generatedAt, packs: [{id, kind, title, count, bytes, file}] }
├── cet4.json       4424 词，约 510 KB
├── cet6.json       5518 词，约 628 KB
└── grammar.json    50 篇，约 344 KB
```

词条结构（键名压缩以减小体积）：

```ts
{ "w": "punctual", "p": "/ˈpʌŋktʃuəl/", "m": "adj. 准时的，守时的；精确的" }
```

> 加载器 `src/services/knowledgePack.ts` 运行时 `fetch(BASE_URL + packs/xxx.json)`，
> 并做内存缓存。**不进主 bundle**，避免拖慢首屏。

## 二、单词闯关（`/quest`）

### 2.1 规则

| 项 | 规则 |
| --- | --- |
| 每组 | 10 题，4 选 1（正确释义 + 3 个同库干扰项） |
| 生命 | 3 条，答错 -1，归零即结束 |
| 计分 | 答对 `10 + min(10, 连击 × 2)` |
| 显示 | 选项只显示**短释义**（首个分号/逗号前，≤24 字），完整释义用于入队与结果页 |
| 进度 | 最高分与局数存 `localStorage: knowflow.quest.progress` |

纯逻辑在 `src/services/quest/engine.ts`（`buildQuestions / answerCurrent / nextQuestion / accuracy`），
不依赖 DOM 与数据库，可单测；随机源可注入（`rng`）以便复现。

### 2.2 答错即入队

`src/services/quest/wordCards.ts`：

1. 首次进入时创建分类「英语」与资料「四级/六级词汇（闯关错词）」，作为卡片容器（便于学习中心回溯来源）
2. 错词若已有同名卡片 → 重置为「不熟悉」；否则新建卡片
3. 统一走 `markMastery(id, 0)`：10 分钟后重新出现，直接进入「今日复习」

这样「玩」和「学」共用同一套记忆调度，而不是两套割裂的系统。

## 三、内置语法包导入

`pages/ImportPage.vue` 顶部新增「内置知识包」卡片：

- 按 `index.json` 列出 `kind: "docs"` 的包（当前为英语语法 50 篇）
- 一键导入：按**标题去重**，分类按专题目录自动创建（定语从句 / 名词性从句 / 时态 …）
- 导入后即为普通资料，可让 AI 提炼要点、生成卡片

## 四、小工具（端内）策略

端内无网络，词库与语法包都加载不了，因此：

| 项 | 处理 |
| --- | --- |
| 路由 | `IS_MINITOOL` 时不注册 `/quest`（也就不会把它打进产物） |
| 加载器 | `@/services/knowledgePack` 用 `minitool/knowledgePack.stub.ts` 替换：索引返回空、词库/语法抛「请用网页版」 |
| 入口 | 侧边栏与首页的「单词闯关」入口端内不渲染 |
| 产物 | `scripts/clean-minitool.mjs` 删除 `dist-minitool/packs` 与 `sw.js` |

验收：`dist-minitool` 内 `fetch(`、`getUserMedia`、`MediaRecorder` 计数均为 **0**，且无 `Quest` chunk。
