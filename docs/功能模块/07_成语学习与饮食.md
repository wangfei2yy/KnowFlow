## 一、数据编译

| 源文件 | 解析要点 | 产出 |
| --- | --- | --- |
| `成语/四字成语大全带解释.(汇总3篇).pdf` | 11 页，条目写法混了 4 种来源（见下），需行内二次切分 | `packs/idiom.json` 172 条 |
| `食谱/家庭健康饮食菜谱精选(1).pdf` | `N.菜名` + `-材料：` + `-做法：`，结构最规整 | `packs/recipes.json` 6 道 |
| `食谱/家常菜谱-简单免费下载可打印.pdf` | `一、菜名` + 数字步骤，部分有「原料/调料」 | 18 道 |
| `食谱/健康菜谱.doc` | Word 老格式，pdfjs 读不了；先用 Word 转 `健康菜谱.txt` 再解析 | 98 道 |
| `食谱/超全一年四季时令蔬菜水果表，(1).pdf` | 按季节分「蔬菜：」「水果：」两行 | `packs/seasons.json` 四季 |

**合并去重后：121 道菜**（午 59 / 晚 56 / 早 6），其中 19 道带材料清单。

### 三个必须记住的解析坑

1. **成语条目有四种写法**，只按「成语：解释」匹配会漏掉一大半：
   - `韬光养晦：比喻隐藏才能`
   - `焦思苦虑解释：着急忧虑`（词条和"解释："连写）
   - `后车之戒(huchēzhījiè)对后面跟上来的车子的警戒`（带拼音）
   - `白草黄云（解释）形容边塞秋季的荒凉景象`
2. **PDF 会把多条词条塞进同一行**（`…白草黄云（解释）…`），必须先按 `词条（解释）` / `词条解释：` 做行内切分，否则长的会把后面全吞进一条（修之前最长释义 963 字）。
3. **Word 导出的换行是单独的 `\r`**，`split(/\r?\n/)` 切不开，整份文档会变成 1 行 → 一条都解析不出来。用 `/[\r\n]+/` 或 `split(/\r\n?|\n/)`。

判定收紧：只保留 **4 字成语**、释义 6~150 字，能一次性把「子里一定在盘算」这类句子碎片过滤掉。

## 二、成语学习（`/study/idiom`）

| 区域 | 说明 |
| --- | --- |
| 工具条 | 搜索（成语 + 释义）、总数、**随机一条** |
| 列表 | 3 列卡片（移动端 2 列），成语 + 释义两行；已加入复习的右上角打绿勾 |
| 详情 | 弹层：成语、完整释义、出处（有则显示）、「加入复习卡片」 |
| 加入复习 | 走 `addWordToReview("idiom", …, false)` → 建卡并挂到「成语复习（闯关错词）」资料下，进「新卡」队列（不当作答错处理） |

### 2.1 筛选（条件写进 URL）

| 维度 | 说明 |
| --- | --- |
| 首字 / 尾字 | 按出现次数排序并带计数，`水（7）` 这种一眼能看出该字有多少条 |
| 字数 | 由现有数据现算，不写死 4 字（后续扩充 5 字成语时不用改） |
| 释义关键词 | 与首字/尾字是**「与」关系**，冲突时返回空而不是忽略其中一个 |
| 掌握度 | 会 / 模糊 / 不会 / 未标 |
| 只看错过 | 与「趣味学习 → 成语填空」的错词记录联动 |

全部条件写进 URL（`?first=水&len=4`），复制链接就能把「含水的四字成语」发给别人；
词库切换不影响，因为成语只有一个包。

### 2.2 三档掌握度（直连 SRS，不新建机制）

| 档位 | 动作 |
| --- | --- |
| 会 | `markWordKnown` —— 把已进队列的卡片按「已掌握」调度，间隔拉长；没建过卡则只记标签 |
| 模糊 | `addWordToReview(..., false)`，正常进队列 |
| 不会 | `addWordToReview(..., true)`，按「答错」处理，首轮更短 |

再点一次取消标记。三档按钮直接放在卡片上，不必开详情 —— 过一遍 172 条的效率差很多。

### 2.3 与游戏打通

成语填空结算时把本局错词累加进 `knowflow.idiom.mistakes`（同局同条只算一次），
成语页显示「错 N」徽标，并支持「只看错过的」。这是唯一一处游戏数据反哺学习页。

**成语闯关**：成语包 `kind: "words"`，会自动出现在闯关页的词库列表（第三张卡）。答题页的音标为空时不显示，其余复用现有引擎，无需额外适配。

## 三、食谱（`/kitchen`）

饮食模块独立于学习：`KitchenLayout` + 三个 Tab（食谱 / 时令 / 计划）。

- 列表：按餐次筛选（早/午/晚）+ 搜索（菜名、材料、标签）+ 标签展示
- 详情：材料 chips、**步骤可点击勾选**（做到哪一步有反馈）、「加入任务清单」
- **冰箱反查**：工具条「我有这些食材」→ 勾选家里现有的（全量铺开 + 可搜索，不截断条数）→
  分两组：「现在就能做」（材料全齐）/「差一两样」（列出缺什么）。
  进「差一两样」要同时满足**缺口 ≤ 2** 且**已覆盖一半以上材料** ——
  只勾两样时若不看覆盖率，几乎每道菜都「差一两样」，列表能到 77 条，等于没筛。
- 材料清单：121 道里 116 道有（96%）。早期 102 道为空，现由
  `scripts/extract-materials.mjs` 从做法文字抽取；抽取不出来的（如「腐乳汁肉」）保持为空，
  页面提示「原文未列材料清单」，宁缺不猜。

## 四、时令（`/kitchen/season`）

四季各一张卡：当季高亮 + 「当季」徽章，蔬菜（绿）与水果（黄）分开列。当前季节按月份推算（3-5 春 / 6-8 夏 / 9-11 秋 / 12-2 冬）。

## 五、饮食计划（`/kitchen/plan`）

**生成规则**（纯前端，不调 AI）：

```
忌口过滤 → 按餐次分池 → 每天早/午/晚各抽一道
        → 同餐次「最近两天不重复」→ 汇总购物清单
```

关键取舍：

- **加权随机**而不是硬性优先：带材料清单的菜权重 3，只写做法的权重 1。试过「只用有材料的菜」，午餐只剩 4 道，7 天会反复出现同样三道；加权后午餐/晚餐能做到 7/7 不重复，购物清单仍覆盖 80+ 种材料。
- **购物清单标注缺口**：概览行显示「共 N 种材料（M 道菜未列材料）」，避免用户以为清单漏了。
- **周期**：一周 7 天 / 四周 28 天，切换后自动重新生成。
- **落地**：「今日菜单加入任务」把当天三餐 + 每步做法写成一条任务，复用任务清单。

**购物清单可操作**：

| 能力 | 说明 |
| --- | --- |
| 勾选 | 点一下划掉；状态按「周一日期」隔离存在 `knowflow.kitchen.checked`，换周自动清空，只保留最近两周 |
| 分组 | 按食材图鉴分类（蔬菜 → 肉蛋 → 水产 → 豆谷 → 菌菇 → 坚果 → 奶 → 其他），图鉴外的归「其他」不丢 |
| 带走 | 「复制清单」导出纯文本 `【蔬菜】/☑ 番茄 ×3`，粘到备忘录就能去超市 |

> 导出比任何新功能都实用：用户真正的动作是「拿着手机去超市」，不是继续在网页上点。

**食材构成**：购物清单下方展示「本周食材构成」——把清单材料按图鉴分类计数（蔬菜 N 种 / 肉类 M 种…）。
只数种数、不折算热量：原始菜谱只写「适量」没有份量，硬算热量是编数字。详见 [模块 09](./09_食材图鉴.md)。

**仍然没有**：热量目标、体重管理。要做这些需要带份量的食谱数据，当前数据源给不出来。

## 七、端内（小工具）策略

成语、食谱、时令都依赖在线知识包（`fetch`），端内一律不注册：

| 项 | 处理 |
| --- | --- |
| 路由 | `IS_MINITOOL` 时不注册 `/study/idiom`、`/kitchen/*` |
| Tab | 学习模块只剩「概览 / 复习」两个 |
| 侧边栏 | 无「成语学习」子项、无「饮食」一级入口 |
| 首页 | 快捷入口过滤掉语法/成语/闯关/饮食 |
| 产物 | `clean-minitool.mjs` 删除 `packs/`；未知路径由兜底路由回首页 |

验收：`dist-minitool` 内 `fetch(` = 0、无 `Idiom`/`Kitchen`/`Recipe` chunk、zip 12 文件审计 PASS。
