# 模块 03 · 任务管理与学习模式

> 从资料到行动的闭环：任务管理负责「去做」，学习模式负责「记住」。
> 返回主文档：[项目说明文档](../项目说明文档.md)

---

## 一、任务管理

### 1.1 任务属性

- 标题、备注
- 优先级：高 / 中 / 低（颜色标识）
- 截止时间 + 逾期标记（红色提示）
- 状态流转：待办 → 进行中 → 已完成

### 1.2 与资料的联动

- 任务可从资料中提取（AI 提取或示例预置），自动携带 `sourceDocumentId`
- 任务列表点击可**回溯来源资料**，跳回原文
- 完成任务时同步提升小知好感度（+5）

## 二、学习模式（学习中心）

学习是一个模块，不是一个页面。`/study` 是外壳（`pages/StudyLayout.vue`），顶部固定四个 Tab，下面用子路由换面板：

| 路径 | 面板 | 说明 |
| --- | --- | --- |
| `/study` | 概览 `StudyOverview.vue` | 今日待复习、卡片总数/已掌握/巩固中、未来 7 天复习量、三个功能入口 |
| `/study/cards` | 卡片复习 `StudyPage.vue` | 原来的学习中心主体（复习/列表双视图） |
| `/study/grammar` | 语法学习 `GrammarPage.vue` | 50 篇语法，端内不注册 |
| `/study/idiom` | 成语学习 `IdiomPage.vue` | 172 条常用成语，端内不注册 |
| `/study/words` | 单词学习 `WordPage.vue` | 四/六级词表逐词浏览 + 加入复习（窗口化列表），端内不注册 |
| `/study/play` | 趣味学习 `PlayHomePage.vue` | 选词库、看成绩、进玩法，端内不注册 |
| `/study/play/quest` | 单词闯关 `QuestPage.vue` | 四六级词库，支持「继续上次那局」，端内不注册 |
| `/study/play/orb` | 单词球球 `OrbPage.vue` | Canvas 限时玩法，端内不注册 |

设计要点：

- **切换 Tab 不整页跳转**：共用 `StudyLayout` 外壳，只有 `<router-view>` 替换，Tab 常驻不闪
- **侧边栏是二级列表**：「学习中心」为父项（带待复习角标，可展开/收起），子项指向各子路由；进入 `/study/*` 时自动展开
- **旧链接兼容**：`/grammar`、`/quest`、`/study/quest` 用 redirect 转到新路径；`/study?mode=review`、`/study?card=xxx` 由概览页检测 query 后 `replace` 到 `/study/cards`，不丢参数
- **只看当前项高亮**：概览用精确匹配（`route.path === "/study"`），否则所有子路由都会点亮它；`/study/play` 用前缀匹配，进去后 Tab 仍亮「趣味学习」
- **端内降级**：不注册语法/成语/游戏子路由，Tab 与侧边栏子项只留「概览 / 复习」
- **导航第 5 项是「单词」**：词库逐词浏览，与语法/成语并列的第四类知识入口
- **导航第 6 项是「趣味学习」**：先后叫过「闯关」「游戏中心」，现在是玩法列表（闯关只是其中一种），详见 [模块 08](./08_学习小游戏.md)
- **Tab 数量到 6 个就是上限**：手机 390px 下 6 个 Tab（2/2/2/2/2/4 字）刚好一屏放下，再加必须横向滚动，所以「食材图鉴」这类子主题不再进 Tab，改放各自模块（饮食）里



### 2.1 双视图

| 视图 | 交互 | 适用场景 |
| --- | --- | --- |
| **复习视图（默认）** | 闪卡翻面：正面问题、点击翻面看答案 | 主动回忆式复习 |
| **列表视图** | 卡片按来源资料分组展示，平铺浏览 | 快速浏览、查找某张卡片 |

### 2.2 复习交互

- 翻卡后标记掌握程度三档：**不熟悉 / 基本掌握 / 已掌握**
- 简单复习间隔：1 / 3 / 7 天（按掌握度自动计算 `nextReviewAt`）
- 掌握卡片时同步提升小知好感度（+4）

### 2.3 筛选与排序（三下拉）

| 下拉 | 选项 |
| --- | --- |
| 分类 | 全部分类 / 各资料分类（含 AI 卡片的来源资料分类，如「英语」「SQL」） |
| 熟悉度 | 全部 / 不熟悉 / 基本掌握 / 已掌握 |
| 排序 | 最近创建 / 最早创建 / 复习优先（到期在前） |

> 实现细节：学习中心加载时会先确保资料分类已加载（`docStore.loadAll()`），再做卡片与分类的关联展示，避免时序问题导致筛选结果为空。

### 2.4 数据说明

- 卡片存于 `flashcards` 表，关键字段：question、answer、mastery、reviewCount、nextReviewAt、createdAt
- 小知 Function Calling 生成的卡片会**直接落入学习中心**，无需手动刷新（入口见 [04_陪伴机器人小知.md](04_陪伴机器人小知.md)）
