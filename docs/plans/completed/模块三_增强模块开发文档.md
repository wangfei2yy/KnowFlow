# 知间 AI（KnowFlow）— 模块三：增强模块开发文档

> 对应规格书「开发阶段」第 4 阶段 + 第 5 阶段（AI 落地）。
> 目标：实现统一 AI Provider 接口与四个 AI 能力——摘要、基于资料的问答、行动项提取、学习卡片生成，并保证无 API Key 时仍可完整演示。

---

## 1. 模块目标与验收标准

| 验收项 | 标准 |
| --- | --- |
| Mock AI | 无 API Key 时，摘要/问答/行动项/卡片均可演示，输出确定性示例 |
| 统一 Provider | 页面组件不散落 API 请求，全部经 AIProvider 接口 |
| 摘要 | 返回 summary + keyPoints + keywords，失败保留原文 |
| 资料问答 | 展示真实来源与原文片段，无证据时明确告知 |
| 行动项提取 | 结果先预览，用户确认后写入任务表并关联来源资料 |
| 卡片生成 | 生成问答对，确认后保存，可翻面复习 |
| 加载/取消 | AI 过程中显示加载态，可取消的任务支持取消 |
| 隐私 | 调用 AI 前告知将发送哪些内容，未经操作不自动发送 |

import type { SummaryResult, SourceContext, AnswerResult, ExtractedTask, FlashcardDraft } from "@/types/ai";

export interface AIProvider {
  readonly name: string;

  answerQuestion(input: { question: string; contexts: SourceContext[] }): Promise<AnswerResult>;

## 4. MockAIProvider.ts

无 API Key 时的确定性演示实现（基于简单规则/关键词，返回可读示例）：

```ts
import type { AIProvider } from "./AIProvider";
import type { SummaryResult, SourceContext, AnswerResult, ExtractedTask, FlashcardDraft } from "@/types/ai";

export class MockAIProvider implements AIProvider {
  readonly name = "MockAIProvider";

  async summarize({ title, content }: { title: string; content: string }): Promise<SummaryResult> {
    const sentences = content.split(/[。！？\n]/).filter((s) => s.trim());
    const first = sentences[0] ?? content.slice(0, 50);
    return {
      summary: `【示例摘要】${first}`,
      keyPoints: sentences.slice(0, 3).map((s) => s.trim()).filter(Boolean),
      keywords: this.extractKeywords(content).slice(0, 5)
    };
  }

  async answerQuestion({ question, contexts }: { question: string; contexts: SourceContext[] }): Promise<AnswerResult> {
    if (contexts.length === 0) {
      return { answer: "现有资料中没有找到足够依据。", sources: [], confidence: "low" };
    }
    const top = contexts[0];
    return {
      answer: `根据资料「${top.title}」：${top.excerpt}`,
      sources: contexts.slice(0, 3),
      confidence: contexts.length >= 2 ? "medium" : "low"
    };
  }

  async extractTasks({ content }: { content: string }): Promise<ExtractedTask[]> {
    const lines = content.split(/[。\n]/).map((s) => s.trim()).filter(Boolean);
    return lines
      .filter((l) => /完成|提交|跟进|确认|准备|整理|评审/.test(l))
      .slice(0, 5)
      .map((l) => ({
        title: l.slice(0, 30),
        description: l,
        dueDate: null,
        priority: /周[一二三四五六日]前|今天|截止|必须/.test(l) ? "high" : "medium",
        evidence: l
      }));
  }

  async generateFlashcards({ content, count }: { content: string; count: number }): Promise<FlashcardDraft[]> {
    const sentences = content.split(/[。！？\n]/).filter((s) => s.trim());
    return sentences.slice(0, count).map((s, i) => ({
      question: `请简述要点 ${i + 1}：`,
      answer: s.trim()
    }));
  }

  private extractKeywords(text: string): string[] {
    const words = text.match(/[a-zA-Z\u4e00-\u9fa5]{2,}/g) ?? [];
    return [...new Set(words)];
  }
}
```

> 说明：Mock 仅用于演示流程，不宣称真实智能。真实接入走 `OpenAICompatibleProvider`（见第 6 节）。

## 5. AI Service 编排（src/services/ai/aiService.ts）

负责：上下文构造、输入长度限制、结构校验、异常处理、job 记录。

```ts
import { db } from "@/db/database";
import { uuid } from "@/utils/uuid";
import type { AIProvider } from "./AIProvider";
import type { AIJob } from "@/types/ai";
import type { Document } from "@/types/document";
import { searchDocuments } from "@/services/searchService";

const MAX_INPUT_CHARS = 12000;

function clampContent(content: string): string {
  return content.length > MAX_INPUT_CHARS ? content.slice(0, MAX_INPUT_CHARS) + "…" : content;
}

export async function runJob(
  provider: AIProvider,
  type: AIJob["type"],
  fn: () => Promise<unknown>,
  documentId?: string
): Promise<unknown> {
  const job: AIJob = {
    id: uuid(),
    documentId,
    type,
    status: "running",
    createdAt: new Date().toISOString()
  };
  await db.aiJobs.add(job);
  try {
    const result = await fn();
    await db.aiJobs.update(job.id, { status: "success", result, completedAt: new Date().toISOString() });
    return result;
  } catch (e) {
    const msg = e instanceof Error ? e.message : "AI 服务暂时不可用";
    await db.aiJobs.update(job.id, { status: "failed", errorMessage: msg, completedAt: new Date().toISOString() });
    throw e;
  }
}

export async function buildQaContexts(question: string, docs: Document[], limit = 3) {
  const results = searchDocuments(docs, question);
  return results.slice(0, limit).map((r) => ({
    documentId: r.document.id,
    title: r.document.title,
    excerpt: r.excerpt ?? r.document.content.slice(0, 120)
  }));
}
```

## 6. OpenAICompatibleProvider.ts（可选真实接入）

```ts
import type { AIProvider } from "./AIProvider";
import type { SummaryResult, SourceContext, AnswerResult, ExtractedTask, FlashcardDraft } from "@/types/ai";

export class OpenAICompatibleProvider implements AIProvider {
  readonly name = "OpenAICompatibleProvider";
  constructor(private baseUrl: string, private apiKey: string, private model: string) {}

  private async chat(messages: { role: string; content: string }[]): Promise<string> {
    const res = await fetch(`${this.baseUrl}/chat/completions`, {
      method: "POST",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${this.apiKey}` },
      body: JSON.stringify({ model: this.model, messages, temperature: 0.3 })
    });
    if (!res.ok) throw new Error(`AI 请求失败：${res.status}`);
    const data = await res.json();
    return data.choices?.[0]?.message?.content ?? "";
  }

  async summarize({ title, content }: { title: string; content: string }): Promise<SummaryResult> {
    const raw = await this.chat([
      { role: "system", content: "你是资料整理助手，只输出 JSON。" },
      { role: "user", content: `标题：${title}\n正文：${content}\n请输出 {"summary": "...", "keyPoints": [...], "keywords": [...]}` }
    ]);
    return parseJSON<SummaryResult>(raw);
  }

  async answerQuestion({ question, contexts }: { question: string; contexts: SourceContext[] }): Promise<AnswerResult> {
    const ctx = contexts.map((c) => `[${c.documentId}] ${c.title}：${c.excerpt}`).join("\n---\n");
    const raw = await this.chat([
      { role: "system", content: "仅根据给定资料回答，引用资料 ID；无依据时明确说明。" },
      { role: "user", content: `资料：\n${ctx}\n\n问题：${question}` }
    ]);
    return parseJSON<AnswerResult>(raw);
  }

  async extractTasks({ content }: { content: string }): Promise<ExtractedTask[]> {
    const raw = await this.chat([
      { role: "system", content: "只提取文本中明确存在的任务，输出 JSON 数组。" },
      { role: "user", content: content }
    ]);
    return parseJSON<ExtractedTask[]>(raw);
  }

  async generateFlashcards({ content, count }: { content: string; count: number }): Promise<FlashcardDraft[]> {
    const raw = await this.chat([
      { role: "system", content: "生成问答卡片，输出 JSON 数组。" },
      { role: "user", content: `生成 ${count} 张卡片：${content}` }
    ]);
    return parseJSON<FlashcardDraft[]>(raw);
  }
}

function parseJSON<T>(raw: string): T {
  try {
    const start = raw.indexOf("{") >= 0 ? raw.indexOf("{") : raw.indexOf("[");
    const cleaned = raw.slice(start).replace(/```json|```/g, "").trim();
    return JSON.parse(cleaned);
  } catch {
    throw new Error("AI 返回格式异常，请重试");
  }
}
```

> 安全：真实 Key 只允许存在服务端/本地 `.env`，**绝不写入前端代码或浏览器存储**。前端默认走 Mock；启用真实模型时应通过 FastAPI 后端代理（模块四）。

## 7. Provider 工厂与配置（src/services/ai/index.ts + settings）

```ts
import { MockAIProvider } from "./MockAIProvider";
import { OpenAICompatibleProvider } from "./OpenAICompatibleProvider";
import type { AIProvider } from "./AIProvider";

export function createProvider(config: {
  mode: "mock" | "openai";
  baseUrl?: string;
  apiKey?: string;
  model?: string;
}): AIProvider {
  if (config.mode === "openai" && config.baseUrl && config.apiKey) {
    return new OpenAICompatibleProvider(config.baseUrl, config.apiKey, config.model ?? "gpt-4o-mini");
  }
  return new MockAIProvider();
}
```

配置存储于 `localStorage`（仅 baseUrl/model，不存 API Key；Key 走后端代理）。默认 `mode = "mock"`。

## 8. 页面接入

### 8.1 DocumentDetailPage 三个 AI 操作

- 「生成摘要」→ `runJob(provider, "summary", ...)` → 结果预览 → 用户确认后 `updateDocument(id, { summary, keywords })`。
- 「提取行动项」→ 结果预览（标题/优先级/证据）→ 用户确认后逐条 `taskStore.create({ ..., sourceDocumentId: id })`。
- 「生成卡片」→ 结果预览 → 用户确认后逐条 `createFlashcard({ documentId: id, ... })`。

所有操作：加载态显示，支持取消；失败保留原文并 toast 错误。

### 8.2 AssistantPage.vue（AI 工作台 `/assistant`）

- Tab：摘要 / 资料问答 / 行动项提取 / 生成卡片。
- 资料问答流程：
  1. 用户输入问题。
  2. `buildQaContexts(question, documents)` 检索相关片段。
  3. 调用 `provider.answerQuestion`。
  4. 展示 answer + sources（可点击打开对应资料详情）。
- 空证据：明确提示「现有资料中没有找到足够依据」。
- 隐私提示：调用前展示「将发送以下内容给 AI」的摘要说明。

### 8.3 取消机制

维护 `AbortController`：

```ts
const controller = new AbortController();
// 传入 fetch 的 signal；取消时 controller.abort()
```

对 Mock Provider（同步/无网络），通过「任务状态标记」模拟取消（`aiJobs.status = failed`，errorMessage = "用户取消"）。

## 9. 结构校验与安全

- 对 AI 返回的 JSON 一律 `parseJSON` 校验，异常时重试一次或提示错误，不直接信任模型输出。
- AI 输出中的指令隔离：资料内容仅作为待分析数据，不触发系统级操作；所有写入（任务、卡片、摘要）必须用户确认。
- 不把模型自生成内容伪装成原文引用；`sources` 只引用真实存在的 `documentId`。
