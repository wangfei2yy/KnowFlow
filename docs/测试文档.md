# 知间 AI（KnowFlow）完整流程测试文档

> 本文档提供从环境准备到全功能验收的完整测试流程，按「模块一 → 模块二 → 模块三 → 模块四」的顺序组织，覆盖核心闭环与边界情况。
> 测试目标：验证应用可运行、数据可靠、核心闭环可用、隐私安全达标。

---

## 一、测试准备

### 1.1 环境要求

| 项 | 要求 |
| --- | --- |
| Node.js | ≥ 18（推荐 22.x） |
| 浏览器 | Chrome / Edge 最新版（需支持 IndexedDB） |
| 后端（可选） | Python ≥ 3.10，conda 环境 `hello_agents` |

### 1.2 启动被测应用

```bash
# 前端
cd frontend
npm install
npm run dev          # 开发预览 http://localhost:5195

# 或生产构建
npm run build
npm run preview      # 预览生产包
```

### 1.3 测试前置动作

1. 打开浏览器无痕窗口（避免历史数据干扰）；
2. 首次进入应用，应看到空状态引导；
3. 点击「加载示例资料」，载入内置示例数据（用于后续多数用例）。

### 1.4 测试数据约定

- 示例资料共 4 条：项目周会记录、数据库索引学习笔记、每周健身计划、Vue 3 组合式 API 要点。
- 测试过程中新增的临时数据，建议在用例结束后删除，保持环境干净。

## 六、核心闭环测试（重点验收）

### TC-CORE-1 会议记录 → 行动项 → 任务闭环

1. 加载示例资料，进入「项目周会记录」；
2. 点「提取行动项」；
3. 确认识别出的任务，点「保存任务」；
4. 进入「任务清单」，看到新任务，状态为「待办」；
5. 点任务「来源」跳回原文；

## 附：常见问题排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 页面空白 | 依赖未装全 | 重新 `npm install` |
| 刷新后数据丢失 | IndexedDB 被清理 | 检查浏览器隐私设置 |
| PDF 无法解析 | 扫描件/加密 PDF | 属预期限制，提示已覆盖 |
| 构建报 safe-delete 错误 | 沙箱安全删除机制 | 先手动删除 `dist/` 再构建 |
| 真实模型调用失败 | 后端未启动/未配 Key | 检查后端与 `.env` |
