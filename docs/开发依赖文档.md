# 知间 AI（KnowFlow）— 开发依赖与环境配置文档

> 本文档说明开发、构建、运行「知间 AI（KnowFlow）」网页应用所需的全部环境、运行时、数据库与第三方依赖，以及各模块间的依赖关系。
> 阅读对象：参与开发的工程师、评审复现者。

---

## 1. 环境总览

| 类别 | 技术 | 版本要求 | 用途 |
| --- | --- | --- | --- |
| 运行时 | Node.js | >= 18（推荐 22.x） | 前端构建与开发 |
| 包管理器 | npm | 随 Node 提供 | 依赖安装 |
| 前端框架 | Vue 3 | ^3.4 | UI 组件化 |
| 语言 | TypeScript | ^5.x | 类型安全 |
| 构建工具 | Vite | ^5.x | 开发与生产构建 |
| 后端运行时 | Python | >= 3.10（实际 3.11.15） | 可选 FastAPI 后端 |
| 环境管理 | Conda | 任意 | Python 环境隔离（使用 `hello_agents`） |
| 浏览器 | Chrome / Edge / Safari 现代版本 | 最新两版 | 运行与体验（依赖 IndexedDB） |

> **核心原则**：MVP 默认「本地优先」，前端不强制依赖后端与数据库服务。数据保存在浏览器 IndexedDB 中，无需安装任何数据库即可运行全部 P0 功能。

## 3. 数据存储（数据库）

### 3.1 前端本地存储：IndexedDB（核心，必需）

- **技术**：浏览器内置 IndexedDB，通过 `Dexie.js` 封装。
- **数据库名**：`knowflow`
- **作用**：持久化保存资料、分类、任务、学习卡片、AI 处理记录，刷新后数据不丢失。
- **无需安装**：IndexedDB 是浏览器标准能力，无需额外安装数据库服务。

数据表结构（Dexie 定义，`schemaVersion` 支持版本迁移）：

| 表 | 主键 | 索引字段 | 说明 |
| --- | --- | --- | --- |
| `documents` | `id` | title, categoryId, favorite, createdAt, updatedAt, *tags | 资料 |
| `categories` | `id` | name, sortOrder | 分类 |
| `tasks` | `id` | status, priority, dueDate, sourceDocumentId, createdAt | 任务 |
| `flashcards` | `id` | documentId, mastery, nextReviewAt | 学习卡片 |
| `aiJobs` | `id` | documentId, type, status, createdAt | AI 处理记录 |

> 所有主键使用 UUID，时间统一 ISO 8601 字符串。

### 3.2 后端数据库（可选，仅云端同步 P2 需要）

MVP 与 P0/P1 阶段**不需要**后端数据库。若要实现 P2 云端同步，可选：

- SQLite（轻量单机）/ PostgreSQL（多用户生产）
- 或 WorkBuddy 云服务提供的云数据库

> 本项目首版不做云端同步，故不强制任何服务端数据库。

## 4. 后端依赖（backend/，可选，仅启用 FastAPI 时）

### 4.1 Python 环境

使用 conda 环境 `hello_agents`：

```bash
conda activate hello_agents
# 环境路径：D:\software\anaconda\anaconda3\envs\hello_agents
python -V   # 实际为 Python 3.11.15（满足 >= 3.10）
```

> **已确认**：`hello_agents` 环境已存在且满足要求。经 `pip list` 核验，后端所需的核心包已预装：`fastapi 0.135.1`、`uvicorn 0.42.0`、`httpx 0.28.1`、`pydantic 2.12.5`、`python-dotenv 1.2.2`、`openai 1.109.1`，另含 `Flask`、`pydantic-settings` 等。因此**启用后端时无需重新安装 `requirements.txt` 中的核心依赖**（如需版本锁定或迁移环境，仍可按第 4.2 节执行 `pip install -r requirements.txt` 补齐）。

### 4.2 Python 包（backend/requirements.txt）

| 包 | 用途 | 是否必需 |
| --- | --- | --- |
| `fastapi` | Web 框架 | 启用后端时必需 |
| `uvicorn[standard]` | ASGI 服务器 | 启用后端时必需 |
| `httpx` | 调用上游模型 | 启用后端时必需 |
| `pydantic` | 请求/响应模型校验 | 启用后端时必需 |
| `python-dotenv` | 读取环境变量 | 启用后端时必需 |

> 后端用途：作为 AI 代理，隐藏真实模型 API Key，并提供输入校验、超时、限流与日志脱敏。前端默认走 MockAIProvider，不依赖后端。

## 5. 环境变量配置

### 5.1 前端（knowflow/.env.example）

前端**不存放任何真实 API Key**。仅可配置非敏感项（如后端代理地址、模型名）：

```bash
# 后端代理地址（启用后端时）
VITE_AI_BASE_URL=http://localhost:8022
# 默认模型名（可选）
VITE_AI_MODEL=gpt-4o-mini
```

### 5.2 后端（backend/.env.example）

真实密钥只允许存服务端，**禁止写入前端代码或提交到仓库**：

```bash
# 模型服务
OPENAI_API_KEY=sk-xxxx
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini

# 跨域允许来源（前端部署地址）
CORS_ORIGINS=http://localhost:5195
```

> `.env` 文件必须加入 `.gitignore`，防止密钥泄漏。

## 6. 安装步骤（从零搭建）

### 6.1 前端

```bash
cd D:/PycharmProjects/ai/AIApplet/KnowFlow

# 1. 创建 Vue3 + TS 项目
npm create vite@latest knowflow -- --template vue-ts

# 2. 进入项目并安装依赖
cd knowflow
npm install

# 3. 安装运行时与工具依赖
npm install vue-router@4 pinia dexie lucide-vue-next pdfjs-dist
npm install -D tailwindcss postcss autoprefixer vue-tsc vitest @vue/test-utils jsdom

# 4. 启动开发
npm run dev        # 开发预览
npm run build      # 生产构建
npm run test       # 测试（模块四）
npm run type-check # 类型检查
```

### 6.2 后端（可选）

```bash
conda activate hello_agents
cd D:/PycharmProjects/ai/AIApplet/KnowFlow/backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8022   # 或直接 python run.py（默认 8022）
```

## 7. 依赖关系与模块映射

| 模块 | 主要依赖 | 数据存储 | 是否需要后端 |
| --- | --- | --- | --- |
| 模块一 基础 | vue/vite/pinia/dexie/tailwind/lucide | IndexedDB | 否 |
| 模块二 完善 | 同上 | IndexedDB | 否 |
| 模块三 增强 | 同上（AI Provider 本地） | IndexedDB（aiJobs） | 否（Mock 模式） |
| 模块四 最终 | + pdfjs-dist、vitest、fastapi | IndexedDB + 可选服务端 | 可选（真实模型代理） |

> 关键：四个模块中，前三模块可在纯前端 + 浏览器 IndexedDB 下完整运行；仅模块四的「真实模型接入」需要可选后端。

## 8. 版本兼容注意事项

1. **Node 版本**：建议 22.x（项目统一管理版本），避免过低版本导致 Vite 5 构建失败。
2. **pdfjs-dist**：需注意 Worker 配置（`import.meta.url`），否则 PDF 解析可能报跨域错误。
3. **Tailwind v3**：本项目用 v3（`content` 配置方式）；若用 v4 需按新 CLI 方式初始化。
4. **Dexie 迁移**：修改表结构必须提升 `version(n)`，禁止改老版本定义。
5. **浏览器兼容**：依赖 IndexedDB，需现代浏览器；建议在最新两版 Chrome/Edge/Safari 验证。
